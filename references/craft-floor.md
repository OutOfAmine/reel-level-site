# Craft floor

Run this list on every section before showing it. These patterns are what make a page read as AI-generated. The idea of a written "floor" comes from [pbakaus/impeccable](https://github.com/pbakaus/impeccable); this list is what held up across real rebuilds.

## Never

- A small uppercase eyebrow above every heading
- An icon in a rounded tile above a heading
- A row of three or four identical cards
- Numbered labels (01, 02, 03) on things that are not a sequence
- Hero metric chips floating around the headline
- Glass panels, gradient text, purple-to-blue gradients
- Tilt or spring on every element
- Unicode arrows; draw an SVG arrow in the same stroke as the other icons
- Thick outlines, hard offset shadows, cartoon buttons
- Inter by default; choose a display face that belongs to the brand's world
- Drawn SVG illustrations standing in for photography

## Always

- One deliberate motion moment per section, and calm around it
- UI borrowed from the subject's own objects
- Flat brand colours and soft shadows on controls: playful concept, restrained finish
- The real logo file
- No dead zones: if a viewer scrolls and nothing changes for a full screen, cut it or give it a reason to exist
- A section reveals as soon as it is on screen, never after a trigger the viewer may have skipped

## Fixed elements

If something stays on screen (a track, a progress bar, a nav), everything else must be laid out around it. Big centred type is the usual victim: split the word between two letters on either side of the element so it never hides one.
